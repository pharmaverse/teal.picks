# teal.picks: Dataset and Variable Picker and Merge Module for 'teal' Applications

Allows users to interactively select datasets, variables, and values
within 'teal' applications using a 'tidyselect'-style interface.
Selected picks can be merged and transformed into analysis-ready data
within 'teal' modules.
